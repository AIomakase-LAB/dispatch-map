# 出動支援マップ

出動時に使う、自分専用の地図アプリ(PWA)。Googleマップのように、開くと現在地の地図が出て、目的地をタップすると車両に合わせた経路を確認できます。iPad/iPhone のブラウザで、現場で片手でも操作できるようにしてあります。
GitHub Pages で配信し、データは本人の Google スプレッドシートに保存します。構成は `kintore-menu`(筋トレメニュー)と同じです。

> **必ず守ること:** 本アプリは OSM に登録された規制・障害物しか検出できません。**現場の状況を優先してください。**(画面上部に常時表示)

## 機能
- **地図**: OpenStreetMap。**起動時は現在地を中心に表示**(位置情報が使えないときは前回の位置、なければ既定の位置。現在地ボタンでいつでも戻れる)
- **現場の書き込み(✏️ 現場タブ)**(すべて端末間で共有・タップで削除): 進入方向(始点→終点の2タップ、「北東向き進入」と方位を自動表示、ラベル付き)/ 通行不可エリア(赤の半透明、理由つき)/ 線 / メモ(ピン)/ 出発地点・目標地点(各事案につき1つ)
- **画面の構成(Googleマップ風)**: 白い面と青のアクセント。上に検索バー風のカード(設定・車両・同期)と項目チップ、下に3つのタブ
  - **🗺 マイマップ**(確認・記録): 普段の記録を見る・書き込む。主な機能の1つ
  - **🛣 経路案内**(主な機能): 地図をタップして目的地を指定 → 現在地から車両に合わせた経路を表示 → 案内開始
  - **✏️ 現場**: 事案ごとの書き込み(進入方向・通行不可エリア・線・メモ)
- **マイマップ(普段の記録)**: 事案とは別に、いつでも表示・共有される自分用の記録。次の**6つの機能項目**にまとめている(チップ・記録ボタン・一覧・経路検索への反映が、同じ6項目で揃っている)
  - 🚪 **進入場所**(進入口・ゲート。1点タップで記録。進入経路は点でなぞって線にもできる)
  - ⛔ **通行止め**(1点または道をなぞって記録。理由つき。**経路検索では常に避ける**)
  - ↔ **狭い道**(線でなぞり、道幅(m)・メモ・「必ず避ける」)
  - 🧯 **消火栓**(続けて何か所でも記録できる)/ 💧 **水利**(川・ため池・プールなど取水できる場所)
  - ⚠ **危険個所**(位置・どんな危険か・範囲の半径・「経路検索で避ける」)
  - **確認**: 上のチップをタップすると、その種類の表示/非表示を切り替え(件数つき)。「📋 記録一覧」で、種類ごとにまとめた一覧を見て、タップでその場所へ移動。記録をタップすると「編集」「削除」。事案を切り替えても消えず、端末間で共有される
- **記録をもとに経路検索**:
  - **経路の再選定**: **通行止め**、「避ける」設定の危険個所と、**車両の幅(+0.3m)では通れない狭い道**(または「必ず避ける」)を、経路検索の回避エリアにして経路を選び直す(出発〜目標に近いものから最大25件)。避けた箇所は経路シートに表示
  - 避ける経路が見つからないときは、避けずに案内し、赤い警告で知らせる
  - **注意表示**: 経路沿いにある危険個所・狭い道を注意箇所に表示(避けきれない・通れない=赤、注意だけ=橙)。案内中は音声でも事前に知らせる。OSMの規制と一緒に一覧に出る
  - **目標付近の水利**: 目標地点の500m以内の消火栓・水利を近い順に一覧表示(タップでその場所へ)
- **車両**: 救急車・消防車・大型車。幅・高さ・重量・長さを画面で入力(端末に保存)
- **通行注意箇所**: 目標地点を置くと、周囲600mの maxwidth / maxheight / maxweight / width / barrier / access / motor_vehicle を Overpass API から取得し、車両寸法と比べて **赤(通行困難の可能性が高い)/ オレンジ(要確認)** で表示。一覧のタップでその場所へ移動
- **経路検索**: 地図で目標地点をタップすると、**現在地から自動で経路を表示**(出発地点を置いた場合はそこから)。Valhalla(truck)に車両寸法を渡し、描いた通行不可エリアを避けて検索。距離・時間・案内文を表示。検索後は経路沿い30mで注意箇所を再取得
- **経路案内(ナビ)**: 経路が出たら「▶ 案内を開始」。現在地に追従し、次の曲がり角の矢印・距離・案内文、残り距離・時間・到着時刻を大きく表示。**日本語の音声で案内**(500m・200m・50m手前)。経路から外れたら**自動でルートを再検索**(現在地から、同じ車両条件・通行不可エリアで)。**前方250m以内の通行注意箇所(赤・橙)を事前に画面と音声で警告**。地図を動かすと追従が止まり、「◎ 現在地」で戻る。案内中は画面が消えないようにし、書き込みボタンは隠す。「🔊 音声」でオン/オフ、「終了」で停止
- **事案・隊名は意識しなくても使える**: 既定は「共通 / 自分」で、初回に入力は求めない。事案を分けたいときだけ ⚙ 設定で切り替える(書き込みは事案ごとに分かれ、隊名が記録される)
- **圏外でも書ける**: 書き込みはまず端末に保存し、送信待ちとして積んでから送る。つながると自動で再送(重複しない)
- 通信に失敗しても画面上部にエラーを出すだけで、アプリは止まりません

## 車両寸法について(最初に必ず実施)
寸法の初期値は入れていません。画面上部の「🚒 車両」から、救急車・消防車・大型車それぞれの**実車の諸元(車検証・カタログ値)**を入力してください(幅・高さ・長さ = m、重量 = t)。
未入力の項目は経路検索・通行判定に使われず、画面に「⚠」「未入力のため判定不可」と表示されます。

## 構成
- 画面: このリポジトリ(静的ファイルのみ、ビルド不要。Leaflet 1.9.4 は CDN から読み込み、`sw.js` がキャッシュ)
- データ API: `AIomakase-LAB/gas-projects` の `projects/dispatch-map`(Google Apps Script)
- 接続: Apps Script の `/exec` を開くとスプレッドシートの「設定」シートに接続コードが書かれる。それをアプリの初回画面に貼る。
  接続コードは API の URL と秘密キーを含むので、他人に渡さないこと。
- 外部APIのURL(地図タイル・Overpass・Valhalla)と同期間隔・検索半径は `app.js` 冒頭の `CONFIG` に集約。自前サーバーに替えるときはここだけ変更する。

## 初回セットアップ
1. **API を用意する**: `gas-projects/projects/dispatch-map/README.md` の手順(Apps Script プロジェクト作成 → `.clasp.json` / `deploy.json` → ウェブアプリとしてデプロイ → `/exec` を開く)
2. **このリポジトリを GitHub に作って公開する**: 新しいリポジトリ(例 `dispatch-map`)にこのフォルダの中身を push し、Settings → Pages で `main` ブランチのルートを配信する。
3. iPhone / iPad の Safari で `https://<ユーザー名>.github.io/dispatch-map/` を開く。
4. スプレッドシート「出動支援マップ(データ)」の「設定」シート **B2(接続コード)** をコピーして貼り付け、「接続」。(事案名・隊名の入力は不要。変えたいときは ⚙ 設定から)。
5. 共有 → 「ホーム画面に追加」。以後はアプリとして全画面で起動する(iPhone と iPad の両方で同じ接続コードを使う)。

リポジトリを公開しても、データ・秘密キーは含まれません(接続コードは各端末の中だけに保存)。

## 更新するとき
`sw.js` の `CACHE` のバージョンを上げると、端末側のキャッシュが入れ替わる。

## 使い方(要点)
- 画面下部の大きなボタンで操作。上段=タブごとの機能項目、下段=3つのタブ。右下の「◎」で現在地へ、上のカードで設定(⚙)・車両・同期
- 進入: 始点→終点の2タップ → ラベル(任意)。通行不可: 頂点を3点以上タップ → 「確定」→ 理由
- 削除: 図形・ピンをタップ → 「🗑 削除」
- 案内: 経路が出たら「▶ 案内を開始」(経路シートの上、または地図上のボタン)。案内中は地図を触ると追従が止まる(「◎ 現在地」で再開)
- 普段の記録: 下の「🗺 マイマップ」タブで、進入場所・通行止め・狭い道・消火栓・水利・危険個所のボタンから、地図をタップして記録する。狭い道は**道幅を入れておくと**、車両の幅より狭いときに自動で避ける
- 経路: 下の「🛣 経路案内」タブで、地図をタップすると目的地になり、現在地から経路を表示する(「目的地」「出発地」ボタンで、地図をタップして指定し直すこともできる)
- 目的地をタップすると、現在地(または設定した出発地点)から経路を検索し、経路沿いの注意箇所も表示。経路がない状態で「注意」を押すと、目標周辺600mを検索
- ⚙ 設定: 事案の切り替え・隊名・事案データの削除・接続コードの入れ直し。「接続せずローカルで試す」を選ぶと、この端末だけに保存(共有なし)

## 案内(ナビ)の注意
- 位置は画面を開いている間だけ更新されます。**画面ロック中・他のアプリに切り替えている間は案内が止まります**(iPhone/iPad の制限)。案内中は自動で画面が消えないようにしていますが、バッテリーに注意してください。
- 音声は端末の音量とマナーモード(消音スイッチ)に従います。聞こえないときは音量とスイッチを確認してください。
- 地図は常に北が上です(進行方向が上になる回転表示はありません)。進行方向は青い矢印で示します。
- 案内の曲がり角の文言・距離は Valhalla の結果に依存します。OSMに登録されていない規制や、実際の道路状況は反映されません。**現場の状況を優先してください。**

## マイマップの注意
- 「事案ごとの書き込み」と「マイマップ」は別の保存先です。マイマップの保存先は事案名の予約名 `マイマップ` で、事案名には使えません。マイマップは一括削除できず、1件ずつ削除します。
- 回避は「出発〜目標を結ぶ線から1.5km(または距離の半分)以内の記録」だけが対象です。回避エリアが多いと経路検索のURLが長くなるため、近いものから最大25件に絞ります。
- 狭い道を避けるかどうかは、道幅と**入力済みの車両の幅**で決まります。車両の幅が未入力のときは「必ず避ける」の設定だけが回避の対象になります。
- 記録は自分で入力した内容です。現地の状況が変わっていることがあるので、**現場の状況を優先してください**。

# API 側(gas-projects/projects/dispatch-map)
